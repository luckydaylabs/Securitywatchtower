# Platform marks

These files are vendored vector marks used only to identify the monitored platforms in the dashboard. The marks remain the property of their respective owners.

- Apple, Linux, and Anthropic icon artwork: [Simple Icons](https://github.com/simple-icons/simple-icons)
- Microsoft window mark: [Microsoft logo on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Microsoft_logo.svg)
- OpenAI mark: [OpenAI design guidelines](https://openai.com/brand/)
